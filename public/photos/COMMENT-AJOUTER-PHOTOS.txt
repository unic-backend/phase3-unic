COMMENT AJOUTER TES VRAIES PHOTOS DE CHANTIER
=============================================

1. Mets tes photos dans ce dossier (public/photos/), ex:
   cuisine.jpg, salon.jpg, etc.

2. Ouvre src/components/Galerie.jsx

3. Pour chaque projet, change "image: null" par le nom du fichier:
   { id: 1, title: "Cuisine Moderne", category: "Cuisine", image: "/photos/cuisine.jpg" },

4. Rebuild: npm run build
5. Redéploie le dossier dist sur Netlify

Tant qu'une photo n'est pas ajoutée, une icône nette s'affiche (plus d'emoji flou).
