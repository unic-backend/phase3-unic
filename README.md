# 🏢 UNIC Plaquiste - Phase 1 (Site Public)

## ✨ Contenu Phase 1

✅ **Hero Section** - Accueil magnifique avec animations
✅ **Services** - 6 services avec cartes animées
✅ **Tarifs** - Calculatrice interactive en temps réel
✅ **Galerie** - Lightbox avec projets avant/après
✅ **FAQ** - Questions fréquentes avec accordéon
✅ **Contact** - Formulaire + liens directs (Tel, Email, WhatsApp)
✅ **Footer** - Complète avec liens et infos légales
✅ **Header** - Navigation fluide + bouton WhatsApp
✅ **Animations** - Fade-in, bounce, smooth scroll

## 🚀 Installation

```bash
npm install
npm run dev
```

Ouvrir: **http://localhost:5173**

## 📦 Build production

```bash
npm run build
```

Le dossier `dist/` contient l'app prête pour Netlify.
