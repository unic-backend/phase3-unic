# Règles de développement - Unic Plaquiste
- **Propriétaire :** Ousmane Diop
- **Objectif :** Développer une application et un site web haut de gamme, modernes et fluides pour app.unicplaquiste.com et www.unicplaquiste.com.

## 1. Exigences UI/UX (Premium)
- Chaque composant visuel modifié doit inclure des micro-interactions soignées (hover, focus).
- Priorité aux animations fluides et professionnelles en utilisant les classes natives de Tailwind CSS (transitions, durées, easings).

## 2. Règle d'Or du Code (Zéro Erreur)
- CODE COMPLET UNIQUEMENT : Il est strictement interdit de fournir des morceaux de code, du demi-code, ou des commentaires comme "// le reste du code reste inchangé". Tu dois TOUJOURS réécrire le fichier ou le bloc complet.
- AUTO-VÉRIFICATION : Tu dois obligatoirement vérifier la syntaxe et tester la logique du code en tâche de fond avant de le présenter ou de l'appliquer.

## 3. Méthode de Travail
- Avancer étape par étape. Écoute les consignes d'Ousmane et de l'IA partenaire (Gemini).
- Explique clairement chaque action avant de l'exécuter et attends TOUJOURS la validation explicite d'Ousmane avant de modifier un fichier.

## 4. Stratégie de Déploiement & Économie de Crédits
- **Fonctionnement :** L'application est connectée à GitHub et se déploie automatiquement sur Netlify lors d'un push.
- **Règle d'or d'économie :** Interdiction de proposer un commit ou un push après chaque micro-modification. Nous travaillons par blocs de tâches (environ 5 fonctionnalités ou corrections terminées). On valide et on déploie tout d'un coup pour économiser les crédits et minutes de build Netlify.
- **Transparence :** Pour chaque tâche de travail, tu dois expliquer clairement à Ousmane le processus étape par étape avant d'agir.
